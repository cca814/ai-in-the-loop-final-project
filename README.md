# Bridging Code and Intent

An AI collaboration layer for software teams. It detects significant changes and design drift across pull requests, issues, and commits, then turns them into the right updates for the right people: technical context for engineers, progress and risk reports for managers.

## Report frontend

See [setup, usage and checks](slide-generator/README.md). The frontend supports Markdown editing, preview, split scrolling and downloads. Data loading, report generation and presentation exports will be connected in a separate backend PR.

Before the frontend PR is merged, use branch `feat/report-frontend`; after it is merged, use `main`.
